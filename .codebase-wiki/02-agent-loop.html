02 · Agent Loop

An agent is a loop that can act, observe, and continue

In Pi, the central loop lives in packages/agent/src/agent-loop.ts. The loop is small enough to read, but it explains most agent behavior.

Beginner model. A chatbot returns text once. An agent returns text plus requests for tools. The harness runs those tools, adds the results to history, and asks the model what to do next.
STEP 1
Start the run. AgentSession collects model, tools, system prompt, context files, skills, and settings, then calls the core agent.
STEP 2
Emit lifecycle events. agent_start, turn_start, message_start, message_update, and message_end let UI and persistence follow along.
STEP 3
Stream from the model. streamAssistantResponse converts Pi messages to provider messages and calls streamSimple from packages/ai/src/stream.ts.
STEP 4
Run tools if requested. If the assistant message contains toolCall blocks, the loop executes them and appends toolResult messages.
STEP 5
Decide whether to continue. The loop may continue for more tool calls, inject queued steering or follow-up messages, compact or swap model state, or end.
