packages/agent is the reusable agent core

This package provides the low-level runtime that Pi's coding agent builds on: stateful agent wrapper, turn loop, tool contracts, session-oriented harness, prompt resources, compaction, and proxy streaming.

Read this as layers. The top-level files are the small reusable core. The harness/ folder adds batteries for apps that need sessions, resources, compaction, and environment adapters.
entry

src/index.ts

Re-exports almost the entire public API. Use it to discover what the package intends callers to import.

state

src/agent.ts

Stateful wrapper around the loop. Owns current state, queues, subscriptions, prompt/continue calls, and active run lifecycle.

loop

src/agent-loop.ts

Pure turn engine. It works with context/config and emits events while keeping UI and persistence outside the loop.

types

src/types.ts

Shared vocabulary: messages, tools, event shapes, hooks, tool execution mode, queue mode, and thinking level.
