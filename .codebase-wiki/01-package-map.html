01 · Package Map

The repo is five packages around one coding agent

Pi separates provider I/O, the generic agent loop, the coding-agent product layer, and UI surfaces. That separation is the first thing to learn.

Rule of thumb. If a bug is about model streaming, start in packages/ai. If it is about turns or tool execution, start in packages/agent. If it is about Pi behavior users see, start in packages/coding-agent.
provider layer

packages/ai

Owns models, provider registration, message formats, streaming events, OAuth helpers, and provider-specific adapters.

runtime layer

packages/agent

Owns the generic loop: send context to model, receive assistant message, execute tool calls, append tool results, repeat.

product layer

packages/coding-agent

Turns the generic loop into Pi: built-in tools, sessions, settings, auth, compaction, skills, extensions, CLI, and modes.

terminal UI

packages/tui

Owns terminal rendering primitives used by interactive mode: components, editor, key handling, and differential screen updates.

browser UI

packages/web-ui

Reusable web components for chat-style agent interfaces and sandboxed message rendering.
